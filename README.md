### 🐛 Projeto 2: Documentação de Bug (Bug Report)
*Mapeamento técnico da falha crítica encontrada no projeto anterior (CT02).*

- **Título do Bug:** Ausência de validação de campo obrigatório na tela de Login (Loop de carregamento).
- **Severidade:** Média (Prejudica a experiência do usuário).
- **Ambiente de Teste:** Google Chrome / Windows 11.
- **Passos para Reproduzir:**
  1. Acessar a URL de login do sistema.
  2. Deixar o campo "E-mail" em branco.
  3. Preencher o campo "Senha".
  4. Clicar no botão "Entrar".
- **Resultado Atual:** O botão trava e a página entra em um loop de carregamento infinito.
- **Resultado Esperado:** O formulário deve bloquear o envio e exibir um aviso visual de campo obrigatório.
